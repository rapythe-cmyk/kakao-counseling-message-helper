# 3주차 과제 제출 요약

## 결과물 링크

- 공개 URL: https://rapythe-cmyk.github.io/kakao-counseling-message-helper/
- 저장소: https://github.com/rapythe-cmyk/kakao-counseling-message-helper

## 3주차 단계 1 - 타겟·메시지·채널

- WHO: 상담 후 카카오톡 안내문을 매일 직접 정리하는 1인 한의원 원장
- WHAT: 상담 끝나고 3분 안에 환자용 카톡 초안 만들기
- WHERE: 가까운 한의사 동료 1:1 데모, 병원 운영자 커뮤니티 공유

## 3주차 단계 2 - 실험 설계와 측정 준비

- 실험: 공개 URL을 테스트 사용자에게 공유하고, 상담 상황 선택 → 안내문 생성 → 위험 표현 검수 → 복사/저장 흐름을 확인한다.
- 정량 기록: 방문, 초안 생성, 복사, 저장, 피드백 제출 횟수를 브라우저에 기록한다.
- 정성 기록: 테스트 사용자가 남긴 좋았던 점, 아쉬웠던 점, 다시 쓸 의향 점수를 저장한다.
- 개선 판단 기준: 초안 생성 후 복사율, 피드백 평균 점수, 반복되는 불편 키워드.

## 3주차 단계 3 - 실제 유저 데려오기

- 공유 채널 1: 가까운 한의사 동료 또는 병원 실무자에게 1:1로 공개 URL 전달
- 공유 채널 2: 병원 운영자 커뮤니티 또는 지인 카톡으로 테스트 요청
- 요청 메시지: "상담 후 환자에게 보낼 카톡 안내문 초안을 만드는 도구입니다. 샘플 상담으로 한 번 생성해보고 좋았던 점과 아쉬웠던 점을 남겨주시면 다음 버전에 반영하겠습니다."

## 3주차 단계 4 - 데이터와 피드백 정리

- 정량: 앱 하단의 3주차 사용 기록 대시보드에서 방문, 생성, 복사, 저장, 피드백 수를 확인한다.
- 정성: 앱 하단 피드백 기록에 테스트 사용자의 반응을 2건 이상 기록한다.
- 합쳐서 보는 신호: 초안은 빠르게 생성되지만, 실제 카톡으로 보내기에는 더 짧은 버전과 자주 쓰는 문구 저장이 필요하다.

## 3주차 단계 5 - Keep · Change · Try

- Keep: 상담 입력 → 초안 생성 → 위험 표현 검수 흐름은 유지한다.
- Change: 초안이 길어지는 문제를 줄이고, 카톡용 짧은 버전을 별도로 제공한다.
- Try: 4주차에는 템플릿 저장과 자주 쓰는 문구 재사용 기능을 추가한다.

## 3주차 한 줄 회고

상담 카톡 초안 생성 자체보다, 실제 업무에 쓰려면 짧은 발송용 문구와 반복 템플릿 저장이 더 중요하다는 점을 확인했다.

## 4주차 개선점

- 메인: 긴 초안과 짧은 카톡 발송용 버전을 분리한다.
- 보조: 자주 쓰는 안내 문구 템플릿 저장 기능을 추가한다.
- 보조: 피드백 기록을 바탕으로 위험 표현 체크 이유를 더 구체적으로 보여준다.
