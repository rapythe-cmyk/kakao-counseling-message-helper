# 1주차 과제: 상담 카톡 안내문 생성·검수 시스템

## 1. 서비스 한 줄 정의
한의원 카카오톡 상담 상황을 입력하면 발송 전 사용할 수 있는 안내문 초안과 검수 체크리스트를 만들어주는 내부 업무 도구.

## 2. 항로
업무 도입 항로.

먼저 한의원 내부 상담 응대 시간을 줄이고, 안내문 품질을 일정하게 만드는 도구로 사용한다. 반복 사용 가치가 확인되면 다른 한의원에서도 사용할 수 있는 템플릿형 서비스로 확장할 수 있다.

## 3. 대상 사용자
- 1차 사용자: 한의원에서 카카오톡 상담을 직접 응대하는 원장 또는 직원
- 2차 사용자: 상담 응대 매뉴얼을 관리하는 운영 담당자

## 4. 문제 정의
### 1층 표면 문제
카카오톡 상담 문의가 올 때마다 비슷한 내용을 반복해서 작성해야 한다.

### 2층 진짜 원인
문의 유형은 반복되지만 환자 상황, 예약 가능 여부, 비용 안내, 내원 전 준비사항에 따라 문장을 매번 조정해야 한다.

### 3층 진짜 고통
바쁜 시간대에는 응대 문장이 급하게 작성되어 누락이 생기거나, 효과 보장·과장 표현·불필요한 개인정보 요청 같은 위험 표현을 놓칠 수 있다.

## 5. 해결책
상담 상황을 선택하거나 직접 입력하면 안내 유형에 맞는 카카오톡 안내문 초안을 만들고, 발송 전 검수해야 할 표현을 함께 보여준다.

## 6. v0.1 핵심 기능 3개
1. 상담 상황 선택 또는 직접 입력
2. 안내 유형과 말투 선택 후 카카오톡 안내문 초안 생성
3. 효과 보장, 최상급 표현, 개인정보 요청, 가격 단정 표현 검수

## 7. 첫 화면 구성
- 작성일 선택
- 상담 소스 선택: 샘플 또는 직접 입력
- 안내 유형 선택: 초진 문의, 예약 안내, 비용 문의, 내원 전 준비, 시술 후 안내, 예약 변경
- 말투 선택: 친절하게, 간결하게, 전문적으로
- 상담 샘플 목록
- 안내문 생성 버튼
- 생성된 안내문 편집 영역
- 위험 표현 검수 결과
- 복사, 브라우저 저장, 다시 생성 버튼

## 8. 이번 버전에서 제외할 것
- 카카오톡 자동 발송
- 로그인
- 결제
- 환자 개인정보 저장
- 병원 CRM 연동
- LLM API 실시간 호출

## 9. 성공 기준
- 상담 상황 하나를 선택하면 안내문 초안 1개가 생성된다.
- 안내문에는 내원 상담 필요, 개인정보 전송 주의, 담당자 최종 확인 문구가 포함된다.
- 위험 표현이 있으면 검수 항목으로 표시된다.
- API 없이도 샘플 데이터로 전체 흐름을 시연할 수 있다.

## 10. 4주 후 도착지
반복 상담 문의 5개 이상에 대해 직원이 바로 검수 후 보낼 수 있는 카카오톡 안내문 초안을 만들고, 위험 표현을 자동으로 점검하는 내부 도구를 완성한다.

## 11. 한 줄 회고
1주차에는 상담 카톡 응대에서 반복되는 문장 작성과 발송 전 검수 문제를 정의하고, 2주차에 만들 수 있는 첫 버전을 상담 입력, 안내문 생성, 위험 표현 검수로 좁혔다.
